# HydroMark — надстройка Markdown для OneNote с ИИ-ассистентом

**HydroMark — это WYSIWYG-надстройка Markdown для Microsoft OneNote в Windows.** Пишите Markdown на странице OneNote, и текст мгновенно преобразуется в нативные элементы OneNote: заголовки, списки, таблицы, списки задач, блоки кода, формулы LaTeX и диаграммы Mermaid. Без экспорта, без скриншотов, без переключения приложений. Начиная с **v1.1.0** встроенный **ИИ-ассистент** записывает готовые статьи, таблицы и выполняет операции со страницей прямо в ваших заметках.

## Что такое HydroMark?

HydroMark — это **надстройка Markdown для OneNote**: надстройка для Windows, которая помещает настоящий редактор Markdown внутрь Microsoft OneNote. Вы продолжаете работать в блокнотах, на холсте и с облачной синхронизацией OneNote, но получаете тот рабочий процесс Markdown, который действительно нужен: введите `## Heading` и пробел — и страница покажет отрисованный заголовок вместо необработанного синтаксиса.

Всё отрисовывается **собственными нативными элементами OneNote, а не изображениями**, поэтому ваши заметки в Markdown остаются редактируемыми, доступными для поиска внутри OneNote, доступными офлайн и синхронизируются с OneNote на телефоне, планшете и в веб-версии. Нажмите `F8`, чтобы экспортировать страницу обратно в `.md`.

Начиная с **v1.1.0** надстройка также включает **ИИ-ассистента**. В отличие от ИИ-панелей, которые выдают текст для копирования и вставки, ИИ HydroMark пишет прямо на страницу: вставляет полностью отрисованные статьи, строит таблицы и выполняет действия надстройки — такие как рендеринг, экспорт, оглавление и ширина страницы — а результаты передаются обратно модели, чтобы она могла подтвердить или скорректировать свои действия.

**Для кого это:** разработчики и технические команды, студенты и исследователи, специалисты по продукту и операциям — все, кто пишет на Markdown, но хранит заметки в OneNote.

### 🤖 ИИ-ассистент — главная возможность (новинка в 1.1.0)

Большинство ИИ-панелей выдают стену текста для копирования и вставки. Ассистент HydroMark **пишет прямо в ваши заметки**:

- **Выполняет действия надстройки, а не просто общается** — вставляет полностью отрисованную статью, строит таблицы, выполняет операции со страницей (рендеринг, экспорт, оглавление, ширина страницы); результаты действий возвращаются в диалог, чтобы модель могла подтвердить или скорректировать свои действия.
- **Таблицы по команде, с нужной вам шириной** — `insert_table` поддерживает раскладку на всю ширину страницы и **по содержимому**; ИИ использует тот же табличный движок, что и переключатель ширины `Alt+W`.
- **Своя модель** — 14 встроенных провайдеров (OpenAI, DeepSeek, Kimi, Zhipu, Qwen…), собственный Base URL для всего остального. Ваш API-ключ остаётся на вашей машине; без промежуточного сервера.
- **Мультимодальность** — вставьте скриншот в чат и обратитесь к нему с мультимодальными моделями.
- **Следование языку** — спросите по-китайски — получите по-китайски; спросите по-английски — получите по-английски.
- **Входит в каждую лицензию** — 14-дневная бесплатная пробная версия и все платные тарифы. Открыть с помощью `Alt+A` или группы **AI** на ленте.

### 📝 Рендеринг Markdown

- **Мгновенный рендеринг Markdown** — наберите `#` или `-` и пробел: строка сразу форматируется; остальные блоки — по Enter или F5 (WYSIWYG).
- **Двойной вид: исходник / отрисованный текст** — переключайтесь между необработанным Markdown и отрисованным выводом в любой момент, для страницы или отдельного абзаца.
- **Вставка Markdown откуда угодно** — `Ctrl+Shift+V` превращает скопированный блок Markdown с веб-страницы, документа или ответа ИИ в готовую заметку.
- **Подсветка кода** — подсветка синтаксиса для 200+ языков, 100+ тем, копирование в один клик.
- **Формулы LaTeX** — встроенные и блочные формулы рендерятся как нативные уравнения OneNote.
- **Диаграммы Mermaid / ZenUML** — 26+ типов диаграмм: блок-схемы, последовательности, классы, состояния, Ганта, интеллект-карты, UML и другие.
- **Таблицы с переключением на всю ширину ↔ по содержимому** — `Alt+W` переключает любую таблицу в обе стороны; состояние «по содержимому» сохраняется.
- **Списки задач** — флажки остаются кликабельными и экспортируются обратно как `- [x]` / `- [ ]`.
- **Слэш-команды** — нажмите `/` для палитры команд и вставляйте блоки быстрым способом.
- **Блоки выделения** — визуально выделяйте важные заметки.
- **Оглавление страницы и ширина страницы** — автоматически создавайте или скрывайте оглавление; ширина страницы вручную или автоматически.
- **Полная адаптация к тёмной теме** — отрисованное содержимое, диалоговые окна и ИИ-панель следуют теме OneNote.
- **Плавный импорт / экспорт** — файлы Markdown на входе, файлы Markdown на выходе (изображения по желанию).

## 🚀 Начало работы

1. **Скачайте** единый многоязычный установщик с сайта [https://hydromark.hydrolinx.top/download](https://hydromark.hydrolinx.top/download) (требуются Windows 7+ и OneNote **desktop** 2013+).
2. **Запустите** установщик — он сам подстраивается под 32- и 64-битный OneNote, отдельного пакета x86 / x64 выбирать не нужно.
3. **Откройте OneNote** и найдите вкладку **HydroMark** на ленте.
4. **Пишите Markdown** — введите `## ` и пробел для заголовка, `- ` и пробел для списка; остальные блоки рендерятся по Enter или `F5`.
5. **Сначала настройте ИИ** — откройте **Настройки → ИИ-модель**, выберите провайдера и введите свой API-ключ (ключ приносите свой; встроено 14 провайдеров). Затем откройте **ИИ-ассистента** с помощью `Alt+A` (или группы **AI** на ленте) и пусть он пишет статьи и таблицы прямо на страницу.
6. **Экспортируйте** текущую страницу в `.md` с помощью `F8`.

14-дневная пробная версия со всеми функциями запускается автоматически — без банковской карты. Полное руководство см. в [документации](https://hydromark.hydrolinx.top/documentation).

## Частые вопросы

**Q: Есть ли надстройка Markdown для OneNote?**

**A:** Да. HydroMark является надстройкой Markdown, созданная специально для Microsoft OneNote desktop в Windows.

**Q: Можно ли использовать ИИ для написания заметок в OneNote?**

**A:** Да. HydroMark включает ИИ-ассистента, который вставляет отрисованные статьи Markdown и таблицы прямо на текущую страницу OneNote и может запускать действия надстройки, такие как рендеринг, экспорт или оглавление.

**Q: Можно вставить изображение и задать по нему вопрос ИИ?**

**A:** Да. Скопируйте изображение или сделайте скриншот и нажмите Ctrl+V в поле ИИ-ассистента, чтобы задать вопрос по картинке; можно приложить несколько изображений к одному вопросу. Нужна модель с поддержкой ввода изображений; если выбранный провайдер её не поддерживает, HydroMark сообщит об этом. Изображения отправляются провайдеру с вашим собственным API-ключом.

**Q: Работает ли HydroMark с OneNote для Windows 10, Mac или мобильными версиями?**

**A:** Нет. HydroMark поддерживает OneNote **desktop** 2013 и новее (2016 / 2019 / 2021 / Microsoft 365) на Windows 7+. Версия OneNote UWP / Microsoft Store, macOS и мобильные версии **не** поддерживаются.

**Q: HydroMark является плагином OneNote или отдельным приложением?**

**A:** Это надстройка OneNote, а не отдельное приложение для заметок. Она устанавливается в OneNote и добавляет вкладку **HydroMark** на ленту; ваши заметки остаются в существующих блокнотах.

**Q: Остаётся ли содержимое Markdown нативным в OneNote?**

**A:** Да. Рендеринг использует нативные элементы OneNote, а не изображения, поэтому заметки остаются редактируемыми, доступными для поиска и синхронизации во всех клиентах OneNote. Страницы по-прежнему можно экспортировать в `.md`.

**Q: Как установить?**

**A:** Скачайте единый многоязычный установщик с сайта, запустите его и откройте OneNote, на ленте появится вкладка **HydroMark**. Установщик автоматически адаптируется к 32- и 64-битному OneNote.

**Q: Это бесплатно?**

**A:** Есть 14-дневная пробная версия с полным набором функций. После этого лицензии приобретаются на устройство (email + ключ): тарифы Individual и Family, Basic и Pro, пожизненные или годовые.
