# HydroMark الدعم — إضافة Markdown لـ OneNote (add-in) مع الذكاء الاصطناعي

[English](README.md) · [简体中文](README.zh.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [हिन्दी](README.hi.md) · **العربية** · **الدعم**

شكرًا لاستخدامك **HydroMark**، إضافة Markdown لـ Microsoft OneNote. توضح هذه الصفحة كيفية الحصول على المساعدة بشأن الإضافة، أو الإبلاغ عن خطأ، أو طلب ميزة.

## قبل الإبلاغ

- حدّث إلى أحدث إصدار من HydroMark.
- راجع [التوثيق](https://hydromark.hydrolinx.top/documentation) و[الأسئلة الشائعة](https://hydromark.hydrolinx.top/faq) و[Issues](../../issues) القائمة.
- تأكد من بيئتك: يعمل HydroMark مع OneNote **سطح المكتب** 2013+ على Windows 7+ مع .NET Framework 4.8+. إصدار UWP / Microsoft Store من OneNote وكذلك macOS والجوال **غير** مدعومين.

## الإبلاغ عن خطأ

افتح [Issue](../../issues) وأرفق ما يلي:

- إصدار Windows وإصدار OneNote (بناء سطح المكتب، 32-بت أو 64-بت)
- إصدار HydroMark لديك
- خطوات إعادة إنتاج المشكلة
- لقطات شاشة أو تسجيل قصير للشاشة إن أمكن
- لمشاكل مساعد الذكاء الاصطناعي: النموذج/المزوّد الذي اخترته (لا تلصق مفتاح API الخاص بك مطلقًا)

## مواضيع متكررة

| الموضوع                   | مكان البحث                                                                                                                                    |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown لا يُعرض         | تحقق أن الصفحة في وضع العرض؛ اضغط `F5` لعرض الصفحة كاملة                                                                                       |
| التبديل بين المصدر والمعروض | متاح للصفحة أو لفقرة مفردة                                                                                                                     |
| كتل الشيفرة و LaTeX و Mermaid | تمييز الشيفرة مشمول في جميع الباقات؛ أما معادلات LaTeX ومخططات Mermaid فهي مزايا Pro — راجع [الأسعار](https://hydromark.hydrolinx.top/pricing) |
| إعداد مساعد الذكاء الاصطناعي | افتحه بـ `Alt+A` ثم اختر مزوّدًا وأدخل مفتاح API الخاص بك                                                                                       |
| الترخيص / تفعيل الجهاز     | تفعيل جهاز جديد ينقل الارتباط ويحرّر المقعد السابق                                                                                              |
| التصدير إلى Markdown       | اضغط `F8` لتصدير الصفحة الحالية إلى `.md`                                                                                                       |
