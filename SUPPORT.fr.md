Merci d'utiliser **HydroMark**, le complément Markdown pour Microsoft OneNote. Cette page explique comment obtenir de l'aide sur le complément, signaler un bug ou demander une fonctionnalité.

## Avant de signaler

- Mettez à jour vers la dernière version de HydroMark.
- Consultez la [Documentation](https://hydromark.hydrolinx.top/documentation), la [FAQ](https://hydromark.hydrolinx.top/faq) et les [Issues](../../issues) existantes.
- Confirmez votre environnement : HydroMark fonctionne avec OneNote **bureau** 2013+ sous Windows 7+ avec .NET Framework 4.8+. La version UWP / Microsoft Store de OneNote, macOS et mobile ne sont **pas** pris en charge.

## Signaler un bug

Ouvrez une [Issue](../../issues) et incluez :

- Votre version de Windows et votre version de OneNote (build bureau, 32 bits ou 64 bits)
- Votre version de HydroMark
- Les étapes de reproduction
- Des captures d'écran ou un court enregistrement d'écran si possible
- Pour les problèmes de l'assistant IA : le modèle/fournisseur que vous avez sélectionné (ne collez jamais votre clé API)

## Demandes de fonctionnalités et idées

Utilisez [Discussions](../../discussions) → « Ideas » pour que la communauté puisse voter.

## Sujets courants

| Sujet                       | Où chercher                                                                                                                                   |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Le Markdown ne s'affiche pas | Vérifiez que la page est en mode rendu ; appuyez sur `F5` pour rendre toute la page                                                          |
| Basculement source / rendu  | Disponible pour la page ou un seul paragraphe                                                                                                 |
| Blocs de code, LaTeX, Mermaid | La coloration syntaxique est incluse dans toutes les offres ; les mathématiques LaTeX et les diagrammes Mermaid sont des fonctions Pro — voir [Tarifs](https://hydromark.hydrolinx.top/pricing) |
| Configuration de l'assistant IA | Ouvrez avec `Alt+A`, puis choisissez un fournisseur et saisissez votre propre clé API                                                     |
| Licence / activation sur appareil | L'activation d'un nouvel appareil transfère la liaison et libère l'ancienne place                                                      |
| Export vers Markdown        | Appuyez sur `F8` pour exporter la page active vers `.md`                                                                                      |
