Obrigado por usar o **HydroMark**, o complemento de Markdown para o Microsoft OneNote. Esta página explica como obter ajuda com o complemento, reportar um erro ou pedir uma funcionalidade.

## Antes de reportar

- Atualize para a versão mais recente do HydroMark.
- Consulte a [Documentação](https://hydromark.hydrolinx.top/documentation), as [Perguntas frequentes](https://hydromark.hydrolinx.top/faq) e os [Issues](../../issues) já existentes.
- Confirme o seu ambiente: o HydroMark funciona com o OneNote de **ambiente de trabalho** 2013+ no Windows 7+ com .NET Framework 4.8+. A versão UWP / Microsoft Store do OneNote, macOS e mobile **não** são suportados.

## Reportar um erro

Abra um [Issue](../../issues) e inclua:

- A sua versão do Windows e do OneNote (versão de ambiente de trabalho, 32 ou 64 bits)
- A sua versão do HydroMark
- Os passos para reproduzir o problema
- Capturas de ecrã ou uma gravação de ecrã curta, se possível
- Para problemas do assistente de IA: o modelo/fornecedor que selecionou (nunca cole a sua chave de API)

## Pedidos de funcionalidades e ideias

Use as [Discussions](../../discussions) → "Ideias" para que a comunidade possa votar.

## Temas frequentes

| Tema                        | Onde consultar                                                                                                                               |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| O Markdown não é renderizado | Confirme que a página está em modo renderizado; prima `F5` para renderizar toda a página                                                     |
| Alternador código-fonte / renderizado | Disponível para a página ou para um único parágrafo                                                                                          |
| Blocos de código, LaTeX, Mermaid | O destaque de código está em todos os planos; as fórmulas LaTeX e os diagramas Mermaid são funcionalidades Pro — consulte [Preços](https://hydromark.hydrolinx.top/pricing) |
| Configuração do assistente de IA | Abra com `Alt+A`, escolha um fornecedor e introduza a sua própria chave de API                                                               |
| Licença / ativação de dispositivo | Ativar um novo dispositivo transfere a vinculação e libera a posição anterior                                                                |
| Exportar para Markdown      | Prima `F8` para exportar a página atual para `.md`                                                                                             |
