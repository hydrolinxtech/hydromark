感謝使用 **HydroMark**，這是一款 Microsoft OneNote 的 Markdown 外掛。本頁面說明如何取得外掛協助、回報錯誤或請求功能。

## 回報之前

- 更新到最新版本的 HydroMark。
- 查看[文件](https://hydromark.hydrolinx.top/documentation)、[常見問題](https://hydromark.hydrolinx.top/faq)以及既有的 [Issues](../../issues)。
- 確認你的環境：HydroMark 適用於 Windows 7+ 上的 OneNote **桌面版** 2013+，並需要 .NET Framework 4.8+。OneNote 的 UWP / Microsoft Store 版本、macOS 與行動版均**不**受支援。

## 回報錯誤

提交 [Issue](../../issues) 並附上：

- 你的 Windows 版本與 OneNote 版本（桌面版組建，32 位元或 64 位元）
- 你的 HydroMark 版本
- 重現步驟
- 如有可能，提供螢幕擷取或簡短的螢幕錄影
- 若是 AI 助理的問題：你選取的模型／供應商（切勿貼上你的 API 金鑰）

## 功能請求與想法

使用 [Discussions](../../discussions) → 「想法」，讓社群可以投票支持。

## 常見主題

| 主題                      | 查閱位置                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown 未渲染           | 檢查頁面是否處於渲染模式；按 `F5` 渲染整個頁面                                                                                                  |
| 原始碼 / 渲染切換         | 可依頁面或單一段落使用                                                                                                                          |
| 程式碼區塊、LaTeX、Mermaid | 程式碼突顯包含在所有方案中；LaTeX 數學公式與 Mermaid 圖表是專業版功能——參見[定價](https://hydromark.hydrolinx.top/pricing)                       |
| AI 助理設定               | 用 `Alt+A` 開啟，接著選擇供應商並輸入你自己的 API 金鑰                                                                                          |
| 授權 / 裝置啟用           | 啟用新裝置會轉移綁定並釋放舊席位                                                                                                                |
| 匯出為 Markdown           | 按 `F8` 將目前頁面匯出為 `.md`                                                                                                                  |
