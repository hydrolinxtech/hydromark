# HydroMark

**A WYSIWYG Markdown editor add-in for Microsoft OneNote.**

Type Markdown directly inside OneNote and watch it render instantly — no exports, no switching apps. Built for developers, students, and technical writers who love OneNote but can't live without Markdown.

## ✨ Features

- **Real-time Markdown rendering** — type Markdown, press Enter, see it formatted instantly (WYSIWYG).
- **Source / rendered dual view** — toggle between raw Markdown and rendered output anytime.
- **Code highlighting** — clean syntax highlighting for dozens of languages.
- **LaTeX math** — inline and block math formulas.
- **Mermaid / ZenUML diagrams** — draw flowcharts, sequence diagrams, and more.
- **Slash commands** — insert blocks the fast way.
- **Highlight blocks** — call out important notes visually.
- **Tables, page-width control, and seamless import / export.**

A special note on the **slash commands** and **highlight blocks**: a big part of why HydroMark was built was exactly those — that's what makes note-taking feel truly modern. And this is just the start: AI-assisted writing, smart summaries, and auto-tagging are on the way.
