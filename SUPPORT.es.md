Gracias por usar **HydroMark**, el complemento de Markdown para Microsoft OneNote. Esta página explica cómo obtener ayuda con el complemento, informar de un error o solicitar una función.

## Antes de informar

- Actualiza a la última versión de HydroMark.
- Consulta la [Documentación](https://hydromark.hydrolinx.top/documentation), las [Preguntas frecuentes](https://hydromark.hydrolinx.top/faq) y los [Issues](../../issues) existentes.
- Confirma tu entorno: HydroMark funciona con OneNote **de escritorio** 2013+ en Windows 7+ con .NET Framework 4.8+. La versión UWP / Microsoft Store de OneNote, macOS y móvil **no** son compatibles.

## Informar de un error

Abre un [Issue](../../issues) e incluye:

- Tu versión de Windows y de OneNote (compilación de escritorio, 32 o 64 bits)
- Tu versión de HydroMark
- Pasos para reproducirlo
- Capturas de pantalla o una grabación de pantalla breve si es posible
- Para problemas del asistente de IA: el modelo/proveedor que seleccionaste (nunca pegues tu clave de API)

## Solicitudes de funciones e ideas

Usa [Discussions](../../discussions) → "Ideas" para que la comunidad pueda votar.

## Temas habituales

| Tema                        | Dónde consultar                                                                                                                               |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown no se renderiza    | Comprueba que la página esté en modo renderizado; pulsa `F5` para renderizar toda la página                                                   |
| Conmutador fuente / renderizado | Disponible para la página o para un solo párrafo                                                                                          |
| Bloques de código, LaTeX, Mermaid | El resaltado de código está en todos los planes; las fórmulas LaTeX y los diagramas Mermaid son funciones Pro — consulta [Precios](https://hydromark.hydrolinx.top/pricing) |
| Configuración del asistente de IA | Ábrelo con `Alt+A`, elige un proveedor e introduce tu propia clave de API                                                               |
| Licencia / activación de dispositivo | Activar un nuevo dispositivo transfiere la vinculación y libera el puesto anterior                                                  |
| Exportar a Markdown         | Pulsa `F8` para exportar la página actual a `.md`                                                                                              |
