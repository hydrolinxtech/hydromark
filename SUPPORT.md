# HydroMark Support — OneNote Markdown Add-in (addin) with AI

Thanks for using **HydroMark**, the Markdown add-in for Microsoft OneNote. This page covers how to get help with the add-in, report a bug, or request a feature.

## Before you report

- Update to the latest version of HydroMark.
- Check the [Documentation](https://hydromark.hydrolinx.top/documentation), the [FAQ](https://hydromark.hydrolinx.top/faq) and existing [Issues](../../issues).
- Confirm your environment: HydroMark works with OneNote **desktop** 2013+ on Windows 7+ with .NET Framework 4.8+. The UWP / Microsoft Store version of OneNote, macOS and mobile are **not** supported.

## Reporting a bug

Open an [Issue](../../issues) and include:

- Your Windows version and OneNote version (desktop build, 32-bit or 64-bit)
- Your HydroMark version
- Steps to reproduce
- Screenshots or a short screen recording if possible
- For AI assistant problems: the model/provider you selected (never paste your API key)

## Feature requests & ideas

Use [Discussions](../../discussions) → "Ideas" so the community can upvote.

## Common topics

| Topic                       | Where to look                                                                                                                                 |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown not rendering      | Check the page is in rendered mode; press `F5` to render the whole page                                                                       |
| Source / rendered toggle    | Available for the page or a single paragraph                                                                                                  |
| Code blocks, LaTeX, Mermaid | Code highlighting is in every plan; LaTeX math and Mermaid diagrams are Pro features — see [Pricing](https://hydromark.hydrolinx.top/pricing) |
| AI assistant setup          | Open with `Alt+A`, then pick a provider and enter your own API key                                                                            |
| License / device activation | Activating a new device transfers the binding and frees the old seat                                                                          |
| Export to Markdown          | Press `F8` to export the current page to `.md`                                                                                                |
