# Support

Thanks for using HydroMark! Here's how to get help and report problems.

## Before you report

- Update to the latest version of HydroMark.
- Check the [Documentation](https://hydromark.hydrolinx.top/documentation) and existing [Issues](../../issues).

## Reporting a bug

Open an [Issue](../../issues) and include:

- Your Windows + OneNote version
- Your HydroMark version
- Steps to reproduce
- Screenshots or a short screen recording if possible

## Feature requests & ideas

Use [Discussions](../../discussions) → "Ideas" so the community can upvote.

## Other contact

📧 support@hydrolinx.top
