# HydroMark 支持 — 带 AI 的 OneNote Markdown 插件

[English](README.md) · **简体中文** · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · **支持**

感谢使用 **HydroMark**，这是 Microsoft OneNote 的 Markdown 插件。本页面介绍如何获取插件帮助、报告缺陷或请求功能。

## 报告之前

- 更新到最新版本的 HydroMark。
- 查看[文档](https://hydromark.hydrolinx.cn/documentation)、[常见问题](https://hydromark.hydrolinx.cn/faq)以及已有的 [Issues](../../issues)。
- 确认你的环境：HydroMark 适用于 Windows 7+ 上的 OneNote **桌面版** 2013+，并需要 .NET Framework 4.8+。OneNote 的 UWP / Microsoft Store 版本、macOS 和移动端均**不**受支持。

## 报告缺陷

提交 [Issue](../../issues) 并包含：

- 你的 Windows 版本和 OneNote 版本（桌面版构建，32 位或 64 位）
- 你的 HydroMark 版本
- 复现步骤
- 如有可能，提供截图或简短录屏
- 如果是 AI 助手问题：你选择的模型 / 服务商（切勿粘贴你的 API 密钥）

## 功能请求与想法

使用 [Discussions](../../discussions) → “Ideas”，让社区可以投票支持。

## 常见主题

| 主题                          | 查阅位置                                                                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown 未渲染               | 检查页面是否处于渲染模式；按 `F5` 渲染整个页面                                                                                              |
| 源码 / 渲染切换               | 可按页面或单个段落使用                                                                                                                      |
| 代码块、LaTeX、Mermaid        | 代码高亮包含在所有版本中；LaTeX 数学公式和 Mermaid 图表是专业版功能——参见[定价](https://hydromark.hydrolinx.cn/pricing)                     |
| AI 助手设置                   | 用 `Alt+A` 打开，然后选择服务商并输入你自己的 API 密钥                                                                                      |
| 授权 / 设备激活               | 激活新设备会转移绑定并释放旧席位                                                                                                            |
| 导出为 Markdown               | 按 `F8` 将当前页面导出为 `.md`                                                                                                              |
