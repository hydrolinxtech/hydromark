**HydroMark هو إضافة (add-in) لتحرير Markdown بما تراه هو ما تحصل عليه، تعمل داخل Microsoft OneNote على نظام Windows.** اكتب Markdown على صفحة OneNote لتُعرض فور الكتابة كمحتوى أصلي في OneNote — العناوين والقوائم والجداول وقوائم المهام وكتل الشيفرة ومعادلات LaTeX ومخططات Mermaid. بلا تصدير ولا لقطات شاشة ولا تبديل بين التطبيقات. منذ **الإصدار 1.1.0** يكتب **المساعد المدمج للذكاء الاصطناعي** المقالات المعروضة والجداول وعمليات الصفحة مباشرة في ملاحظاتك.

## ما هو HydroMark؟

HydroMark هو **إضافة Markdown لـ OneNote**: إضافة على Windows تضع محرر Markdown حقيقيًا داخل Microsoft OneNote. تبقى على الكتابة في دفاتر ملاحظاتك ومساحة العمل والمزامنة السحابية كما هي، لكنك تحصل على سير عمل Markdown الذي تريده فعلًا — اكتب `## Heading` ثم مسافة لتظهر لك صفحة بعنوان معروض بدل الصيغة الخام.

كل شيء يُعرض بعناصر **أصلية من OneNote وليس صورًا**، لذلك تبقى ملاحظات Markdown قابلة للتحرير وصالحة للبحث داخل OneNote ومتاحة دون اتصال ومتزامنة مع OneNote على الهاتف والجهاز اللوحي والويب. اضغط `F8` لتصدير صفحة مرة أخرى إلى `.md`.

منذ **الإصدار 1.1.0** تتضمن الإضافة أيضًا **مساعد ذكاء اصطناعي**. وعلى عكس الأشرطة الجانبية للذكاء الاصطناعي التي تعطيك نصًا لتنسخه وتلصقه، يكتب مساعد HydroMark داخل الصفحة نفسها: يُدرج مقالات معروضة بالكامل، ويبني الجداول، وينفّذ عمليات الإضافة مثل العرض والتصدير وجدول المحتويات وعرض الصفحة — ثم تُعاد نتائج كل عملية إلى النموذج ليؤكد النتيجة أو يصححها بنفسه.

**لمن هذه الإضافة:** المطوّرون والفرق التقنية، والطلاب والباحثون، وفرق المنتج والتشغيل — كل من يكتب Markdown ويحتفظ بملاحظاته في OneNote.

## ✨ المزايا

### 🤖 مساعد الذكاء الاصطناعي — الميزة الأبرز (جديدة في 1.1.0)

معظم الأشرطة الجانبية للذكاء الاصطناعي تمنحك كتلة نص لنسخها ولصقها. أما مساعد HydroMark **فيكتب داخل ملاحظاتك**:

- **ينفّذ عمليات الإضافة ولا يكتفي بالمحادثة** — يُدرج مقالًا معروضًا بالكامل، ويبني الجداول، وينفّذ عمليات الصفحة (العرض، التصدير، جدول المحتويات، عرض الصفحة)؛ وتعود نتائج العمليات إلى المحادثة ليتمكن النموذج من التأكيد أو تصحيح نفسه.
- **جداول عند الطلب وبالعرض الذي طلبته** — تدعم `insert_table` عرض الصفحة الكامل والتخطيط **المُلائم للمحتوى**؛ ومسار الذكاء الاصطناعي يستخدم محرّك الجداول نفسه الذي يعمل به مفتاح `Alt+W` لتبديل العرض.
- **اختيار النموذج بيدك** — 14 مزوّدًا مدمجًا (OpenAI و DeepSeek و Kimi و Zhipu و Qwen…)، مع Base URL مخصص لأي مزوّد آخر. يبقى مفتاح API الخاص بك على جهازك فقط، بلا خادم وسيط.
- **متعدد الوسائط** — الصق لقطة شاشة في المحادثة وأشِر إليها باستخدام النماذج متعددة الوسائط.
- **يتّبع لغتك** — اسأل بالعربية تحصل على عربية، وبأي لغة تسأل تُجبَ بها.
- **مشمول في كل ترخيص** — في تجربة 14 يومًا المجانية وفي جميع الباقات المدفوعة. افتحه بـ `Alt+A` أو من مجموعة **AI** في الشريط.

### 📝 عرض Markdown

- **عرض Markdown أثناء الكتابة** — اكتب `#` أو `-` ثم مسافة لتجد التنسيق مطبقًا فورًا؛ تُعرض البلوكات الأخرى بدخول Enter أو F5 (ما تراه هو ما تحصل عليه).
- **عرض مزدوج: المصدر والمعروض** — بدّل بين Markdown الخام والمخرجات المعروضة في أي وقت، على مستوى الصفحة أو الفقرة.
- **الصق Markdown من أي مصدر** — يحوّل `Ctrl+Shift+V` كتلة Markdown منسوخة من صفحة ويب أو مستند أو إجابة ذكاء اصطناعي إلى ملاحظة مكتملة.
- **تمييز الشيفرة** — تمييز صيغة لأكثر من 200 لغة برمجة وأكثر من 100 سمة، مع نسخ بنقرة واحدة.
- **معادلات LaTeX** — المعادلات ضمن السطر وفي الكتل تُعرض كمعادلات أصلية في OneNote.
- **مخططات Mermaid / ZenUML** — أكثر من 26 نوعًا من المخططات: مخططات انسيابية وتسلسل وفئات وحالة وغانتر وخرائط ذهنية و UML وغيرها.
- **جداول بتبديل بين عرض الصفحة الكامل وملاءمة المحتوى** — يبدّل `Alt+W` أي جدول في الاتجاهين، وتُحفظ حالة الملاءمة للمحتوى.
- **قوائم المهام** — تبقى مربعات الاختيار قابلة للنقر وتُصدَّر بصيغة `- [x]` / `- [ ]`.
- **أوامر الشرطة المائلة** — اضغط `/` لفتح لوحة الأوامر وإدراج الكتل بسرعة.
- **كتل تمييز** — أبرز الملاحظات المهمة بصريًا.
- **جدول محتويات الصفحة وعرضها** — أنشئ جدول المحتويات تلقائيًا أو أخفِه؛ وحدد عرض الصفحة يدويًا أو تلقائيًا.
- **مواءمة كاملة للوضع الداكن** — المحتوى المعروض ونوافذ الحوار والشريط الجانبي للذكاء الاصطناعي تتبع جميعها سمة OneNote.
- **استيراد / تصدير بلا احتكاك** — ملفات Markdown تدخل وملفات Markdown تخرج (الصور اختيارية).

## أسئلة شائعة

**هل توجد إضافة Markdown لـ OneNote؟**
نعم — HydroMark إضافة Markdown (add-in) صُمِّمت خصيصًا لـ Microsoft OneNote على سطح المكتب في Windows.

**هل أستطيع استخدام الذكاء الاصطناعي لكتابة الملاحظات في OneNote؟**
نعم. تتضمن الإضافة مساعد ذكاء اصطناعي يُدرج مقالات وجداول Markdown معروضة مباشرة في صفحة OneNote الحالية، ويمكنه أيضًا تنفيذ عمليات إضافة مثل العرض والتصدير وإنشاء جدول المحتويات.

**هل يعمل HydroMark مع OneNote for Windows 10 أو Mac أو الجوال؟**
لا. يدعم HydroMark OneNote **سطح المكتب** 2013 وما بعده (2016 / 2019 / 2021 / Microsoft 365) على Windows 7+. إصدار UWP / Microsoft Store من OneNote وكذلك macOS والجوال **غير** مدعومين.

**هل HydroMark إضافة لـ OneNote أم تطبيق مستقل؟**
إنه إضافة لـ OneNote وليس تطبيق ملاحظات مستقلًا. يُثبَّت داخل OneNote ويضيف تبويب **HydroMark** إلى الشريط، وتبقى ملاحظاتك في دفاترك الحالية.

**هل يبقى محتوى Markdown أصليًا داخل OneNote؟**
نعم. يعتمد العرض على عناصر OneNote الأصلية بدل الصور، فتبقى الملاحظات قابلة للتحرير والبحث ومتزامنة بين عملاء OneNote. كما يمكن تصدير الصفحات إلى `.md`.

**كيف أثبّته؟**
نزّل ملف التثبيت أحادي الملف متعدد اللغات من الموقع، وشغّله ثم افتح OneNote ليظهر تبويب **HydroMark** في الشريط. يتكيّف ملف التثبيت تلقائيًا مع OneNote بنسختيه 32-بت و 64-بت.

**هل هو مجاني؟**
تتوفر تجربة كاملة المزايا لمدة 14 يومًا. بعدها تكون التراخيص لكل جهاز (بريد إلكتروني + مفتاح): باقات فردية وعائلية، وأساسية واحترافية، مدى الحياة أو سنويًا.
