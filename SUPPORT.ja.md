# HydroMark サポート — AI 搭載の OneNote Markdown アドイン

[English](README.md) · [简体中文](README.zh.md) · **日本語** · [한국어](README.ko.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · **サポート**

**HydroMark**（Microsoft OneNote 向け Markdown アドイン）をご利用いただきありがとうございます。このページでは、アドインのヘルプの入手方法、バグの報告方法、機能リクエストの方法を説明します。

## 報告する前に

- HydroMark を最新バージョンに更新してください。
- [ドキュメント](https://hydromark.hydrolinx.top/documentation)、[FAQ](https://hydromark.hydrolinx.top/faq)、既存の [Issues](../../issues) を確認してください。
- 環境を確認してください：HydroMark は Windows 7+ 上の OneNote **デスクトップ版** 2013+ と .NET Framework 4.8+ で動作します。OneNote の UWP / Microsoft Store 版、macOS、モバイルには**対応していません**。

## バグの報告

[Issue](../../issues) を作成し、以下を含めてください：

- Windows のバージョンと OneNote のバージョン（デスクトップ版のビルド、32 ビットまたは 64 ビット）
- HydroMark のバージョン
- 再現手順
- 可能であればスクリーンショットまたは短い画面録画
- AI アシスタントの問題の場合：選択したモデル / プロバイダー（API キーは絶対に貼り付けないでください）

## 機能リクエストとアイデア

[Discussions](../../discussions) → 「Ideas」を利用して、コミュニティが投票できるようにしてください。

## よくあるトピック

| トピック                       | 確認先                                                                                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown がレンダリングされない | ページがレンダリングモードになっているか確認してください。`F5` でページ全体をレンダリングできます                                              |
| ソース / レンダリングの切り替え | ページ単位または単一段落単位で利用できます                                                                                                      |
| コードブロック、LaTeX、Mermaid  | コードハイライトはすべてのプランに含まれます。LaTeX 数式と Mermaid ダイアグラムは Pro 機能です——[価格](https://hydromark.hydrolinx.top/pricing)をご覧ください |
| AI アシスタントの設定          | `Alt+A` で開き、プロバイダーを選んでご自身の API キーを入力してください                                                                          |
| ライセンス / デバイスの認証    | 新しいデバイスを認証するとバインディングが移り、以前のシートが解放されます                                                                      |
| Markdown へのエクスポート      | `F8` で現在のページを `.md` に書き出せます                                                                                                      |
