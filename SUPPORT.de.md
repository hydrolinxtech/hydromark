Danke, dass Sie **HydroMark** verwenden, das Markdown-Add-in für Microsoft OneNote. Diese Seite beschreibt, wie Sie Hilfe zum Add-in erhalten, einen Fehler melden oder eine Funktion wünschen.

## Bevor Sie melden

- Aktualisieren Sie auf die neueste Version von HydroMark.
- Prüfen Sie die [Dokumentation](https://hydromark.hydrolinx.top/documentation), die [FAQ](https://hydromark.hydrolinx.top/faq) und bestehende [Issues](../../issues).
- Bestätigen Sie Ihre Umgebung: HydroMark funktioniert mit OneNote **Desktop** 2013+ unter Windows 7+ mit .NET Framework 4.8+. Die UWP-/Microsoft-Store-Version von OneNote, macOS und Mobilgeräte werden **nicht** unterstützt.

## Einen Fehler melden

Öffnen Sie ein [Issue](../../issues) und geben Sie an:

- Ihre Windows-Version und OneNote-Version (Desktop-Build, 32-Bit oder 64-Bit)
- Ihre HydroMark-Version
- Schritte zur Reproduktion
- Screenshots oder eine kurze Bildschirmaufnahme, wenn möglich
- Bei Problemen mit dem KI-Assistenten: das gewählte Modell/den Anbieter (niemals Ihren API-Schlüssel einfügen)

## Funktionswünsche & Ideen

Nutzen Sie [Discussions](../../discussions) → „Ideen“, damit die Community abstimmen kann.

## Häufige Themen

| Thema                       | Wo nachsehen                                                                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown wird nicht gerendert | Prüfen Sie, ob die Seite im gerenderten Modus ist; drücken Sie `F5`, um die ganze Seite zu rendern                                         |
| Umschalten Quelle / gerendert | Für die ganze Seite oder einen einzelnen Absatz verfügbar                                                                                   |
| Codeblöcke, LaTeX, Mermaid  | Code-Hervorhebung ist in jedem Tarif enthalten; LaTeX-Formeln und Mermaid-Diagramme sind Pro-Funktionen — siehe [Preise](https://hydromark.hydrolinx.top/pricing) |
| Einrichtung des KI-Assistenten | Mit `Alt+A` öffnen, dann Anbieter wählen und eigenen API-Schlüssel eingeben                                                              |
| Lizenz / Geräteaktivierung  | Die Aktivierung eines neuen Geräts überträgt die Bindung und gibt den alten Platz frei                                                       |
| Export nach Markdown        | Drücken Sie `F8`, um die aktuelle Seite nach `.md` zu exportieren                                                                            |
