# Поддержка HydroMark — надстройка Markdown для OneNote с ИИ

[English](README.md) · [简体中文](README.zh.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · **Русский** · [Deutsch](README.de.md) · [Français](README.fr.md) · **Поддержка**

Спасибо за использование **HydroMark** — надстройки Markdown для Microsoft OneNote. Эта страница рассказывает, как получить помощь по надстройке, сообщить об ошибке или запросить функцию.

## Перед обращением

- Обновитесь до последней версии HydroMark.
- Проверьте [Документацию](https://hydromark.hydrolinx.top/documentation), [FAQ](https://hydromark.hydrolinx.top/faq) и существующие [Issues](../../issues).
- Подтвердите своё окружение: HydroMark работает с OneNote **desktop** 2013+ на Windows 7+ с .NET Framework 4.8+. Версия OneNote UWP / Microsoft Store, macOS и мобильные версии **не** поддерживаются.

## Сообщение об ошибке

Создайте [Issue](../../issues) и укажите:

- Вашу версию Windows и версию OneNote (сборка desktop, 32 или 64 бита)
- Вашу версию HydroMark
- Шаги воспроизведения
- Скриншоты или короткую запись экрана, если возможно
- Для проблем с ИИ-ассистентом: выбранную модель / провайдера (никогда не вставляйте свой API-ключ)

## Запросы функций и идеи

Используйте [Discussions](../../discussions) → «Ideas», чтобы сообщество могло голосовать.

## Частые темы

| Тема                              | Где искать                                                                                                                                    |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown не рендерится            | Проверьте, что страница в режиме отрисовки; нажмите `F5`, чтобы отрисовать всю страницу                                                        |
| Переключение исходник / отрисованный текст | Доступно для страницы или отдельного абзаца                                                                                          |
| Блоки кода, LaTeX, Mermaid        | Подсветка кода есть во всех тарифах; формулы LaTeX и диаграммы Mermaid — функции Pro — см. [Цены](https://hydromark.hydrolinx.top/pricing)     |
| Настройка ИИ-ассистента           | Откройте с помощью `Alt+A`, затем выберите провайдера и введите свой API-ключ                                                                 |
| Лицензия / активация устройства   | При активации нового устройства привязка переносится, а старое место освобождается                                                            |
| Экспорт в Markdown                | Нажмите `F8`, чтобы экспортировать текущую страницу в `.md`                                                                                   |
