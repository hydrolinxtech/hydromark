**HydroMark は、Windows 版 Microsoft OneNote 向けの WYSIWYG Markdown アドインです。** OneNote ページに Markdown を入力して Enter を押すと、見出し、リスト、表、タスクリスト、コードブロック、LaTeX 数式、Mermaid 図が OneNote ネイティブの内容として瞬時にレンダリングされます。エクスポートもスクリーンショットも、アプリの切り替えも不要です。**v1.1.0** 以降、内蔵の **AI アシスタント**がレンダリング済みの記事や表、ページ操作をノートに直接書き込みます。

## HydroMark とは？

HydroMark は **OneNote Markdown アドイン**です。Microsoft OneNote の中に本物の Markdown エディターを組み込む Windows アドインです。OneNote のノートブック、キャンバス、クラウド同期はそのままに、本当に欲しかった Markdown ワークフローを手に入れられます。`## Heading` と入力して Enter を押せば、生の構文ではなくレンダリングされた見出しがページに表示されます。

すべての内容は**画像ではなく OneNote ネイティブの要素**でレンダリングされるため、Markdown ノートは編集可能なまま、OneNote 内で検索でき、オフラインでも使え、スマートフォン、タブレット、Web 版の OneNote にも同期されます。`F8` を押すとページを `.md` に書き出せます。

**v1.1.0** 以降、このアドインには **AI アシスタント**も搭載されています。コピー＆ペースト用のテキストを渡すだけの AI サイドバーとは違い、HydroMark の AI はページに直接書き込みます。完全にレンダリングされた記事を挿入し、表を構築し、レンダリング、エクスポート、目次、ページ幅といったアドイン操作を実行します。操作の結果はモデルに返されるので、モデル自身が確認や自己修正を行えます。

**こんな方に：** 開発者や技術チーム、学生や研究者、プロダクトや運用担当者——Markdown で書きながらノートは OneNote に置いておきたい、というすべての方に。

## ✨ 機能

### 🤖 AI アシスタント — 目玉機能（1.1.0 で新登場）

多くの AI サイドバーは、コピー＆ペーストするためのテキストの塊を渡すだけです。HydroMark のアシスタントは**ノートに直接書き込みます**：

- **チャットだけでなく、アドイン操作を実行** — 完全にレンダリングされた記事の挿入、表の構築、ページ操作（レンダリング、エクスポート、目次、ページ幅）の実行。操作結果は会話にフィードバックされるため、モデルは確認や自己修正ができます。
- **指定した幅で表をコマンド一発** — `insert_table` はページ全幅と**内容に合わせる**レイアウトに対応。AI 経由の処理は `Alt+W` の幅切り替えと同じ表エンジンを共有します。
- **お好みのモデルを持ち込み** — 15 のプロバイダーを内蔵（OpenAI、DeepSeek、Kimi、Zhipu、Qwen…）。それ以外は Base URL をカスタム指定できます。API キーはお使いのマシン上に留まり、中継サーバーはありません。
- **マルチモーダル** — チャットにスクリーンショットを貼り付け、マルチモーダルモデルで参照できます。
- **言語に追従** — 中国語で質問すれば中国語で、英語で質問すれば英語で回答します。
- **すべてのライセンスに含まれる** — 14 日間の無料トライアルとすべての有料プラン。`Alt+A` またはリボンの **AI** グループから開けます。

### 📝 Markdown レンダリング

- **リアルタイム Markdown レンダリング** — Markdown を入力して Enter を押すと、即座に整形されて表示されます（WYSIWYG）。
- **ソース / レンダリングのデュアルビュー** — 生の Markdown とレンダリング結果をいつでも切り替え可能。ページ単位でも段落単位でも切り替えられます。
- **どこからでも Markdown を貼り付け** — `Ctrl+Shift+V` で、Web ページやドキュメント、AI の回答からコピーした Markdown のブロックを完成したノートに変えます。
- **コードハイライト** — 200 以上の言語、100 以上のテーマに対応したシンタックスハイライト、ワンクリックコピー。
- **LaTeX 数式** — インライン数式もブロック数式も OneNote ネイティブの数式としてレンダリングされます。
- **Mermaid / ZenUML ダイアグラム** — 26 以上の図の種類：フローチャート、シーケンス図、クラス図、状態遷移図、ガントチャート、マインドマップ、UML など。
- **表の全幅 ↔ 内容に合わせる切り替え** — `Alt+W` でどの表も双方向に切り替えられます。内容に合わせた状態は保持されます。
- **タスクリスト** — チェックボックスはクリック可能なまま、`- [x]` / `- [ ]` として書き出せます。
- **スラッシュコマンド** — `/` を押すとコマンドパレットが開き、ブロックを素早く挿入できます。
- **ハイライトブロック** — 重要なノートを視覚的に目立たせます。
- **ページ目次とページ幅** — 目次の自動生成や非表示、ページ幅の手動・自動調整ができます。
- **ダークモードに完全対応** — レンダリング内容、ダイアログ、AI サイドバーがすべて OneNote のテーマに追従します。
- **シームレスなインポート / エクスポート** — Markdown ファイルを読み込み、Markdown ファイルとして書き出し（画像は任意）。

## よくある質問

**OneNote 用の Markdown アドインはありますか？**
はい——HydroMark は、Windows 版 Microsoft OneNote デスクトップ専用に作られた Markdown アドインです。

**OneNote で AI を使ってノートを書けますか？**
はい。HydroMark には AI アシスタントが搭載されており、レンダリング済みの Markdown 記事や表を現在の OneNote ページに直接挿入し、レンダリング、エクスポート、目次といったアドイン操作を実行できます。

**HydroMark は OneNote for Windows 10、Mac、モバイルで使えますか？**
いいえ。HydroMark は Windows 7+ 上の OneNote **デスクトップ版** 2013 以降（2016 / 2019 / 2021 / Microsoft 365）に対応しています。OneNote の UWP / Microsoft Store 版、macOS、モバイルには**対応していません**。

**HydroMark は OneNote のプラグインですか、それとも別のアプリですか？**
OneNote のアドインであり、独立したノートアプリではありません。OneNote にインストールされ、リボンに **HydroMark** タブを追加します。ノートは既存のノートブックにそのまま残ります。

**Markdown の内容は OneNote 内でネイティブのままですか？**
はい。レンダリングには画像ではなく OneNote ネイティブの要素を使うため、ノートは編集可能で検索可能なまま、各 OneNote クライアント間で同期できます。ページは引き続き `.md` に書き出せます。

**インストール方法は？**
公式サイトから単一の多言語インストーラーをダウンロードして実行し、OneNote を開くと、リボンに **HydroMark** タブが表示されます。インストーラーは 32 ビット版と 64 ビット版の OneNote に自動で対応します。

**無料ですか？**
14 日間の全機能トライアルがあります。その後はデバイス単位のライセンス（メール + キー）です。個人版とファミリー版、Basic と Pro、買い切りまたは年間から選べます。
